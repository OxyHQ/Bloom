# Composition rollout

## Archive status — 2026-11-08

This ledger preserves earlier local integration evidence. All versions, pending
release decisions, branch names, running ports and remaining-work descriptions
below are historical observations, not current instructions or verified live
state. Current main is `e3996b93` (17.22.0). Issue [#663](https://github.com/OxyHQ/Bloom/issues/663)
tracks the current implementation and acceptance work; the
[implementation inventory](/docs/composition-inventory) records its source baseline.
Revalidate every consumer and artifact before reusing an old result. Nothing
in this archive authorizes publication or replaces physical-device acceptance.

This is an implementation ledger, not a claim that the fleet is standardized.
The approved appearance of Mention, Inbox and other existing applications is
an acceptance constraint. Storybook examples should teach the actual public
composition API, and each consumer should keep its business data and actions.
