# Android emulator performance sample · 2026-11-09

The dedicated API 36 emulator used x86_64 with SwiftShader. It was installed from the same synthetic Bloom 17.25.0 package fixture; `environment.json` records the device and APK hashes.

Two of the six planned benchmark cases completed before the emulator disconnected: one loader with no taper and two loaders with no taper. Their reports and captures are retained here as partial observations. They are not performance acceptance: this emulator's software graphics path is not representative of a Pixel GPU, and the planned matrix did not finish.
