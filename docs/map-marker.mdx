# Map Marker

The pieces a listings map is made of. Bloom ships no map: these render
anywhere, and the app's map library positions them.

```tsx
import {
  MapAreaCircle,
  MapClusterMarker,
  MapListingPreview,
  MapPriceMarker,
  MapSearchAreaButton,
} from '@oxy.so/bloom/map-marker';

<MapPriceMarker
  price="€120"
  state={activeId === id ? 'active' : visited.has(id) ? 'visited' : 'default'}
  saved={saved.has(id)}
  onPress={() => open(id)}
  accessibilityLabel="€120 per night, Valdoria"
/>

<MapPriceMarker price="€240K" size="compact" accessibilityLabel="€240,000, Talmar Hill" />

<MapAreaCircle radius={metresToPixels(500)} label="~500 m" accessibilityLabel="Approximate location" />

<MapClusterMarker count={14} onPress={zoomIn} />

<MapListingPreview
  image={listing.photo}
  title="Cabin by the pines"
  rating={4.92}
  reviewCount={128}
  subtitle="Entire cabin · 2 beds"
  price="€120"
  priceDetail="night"
  favorite={saved.has(id)}
  onFavoriteChange={toggleSaved}
  onClose={close}
  onPress={openListing}
/>

<MapSearchAreaButton variant="toggle" checked={follow} onCheckedChange={setFollow} />
<MapSearchAreaButton onPress={searchHere} />
```

Placement is the app's: centre a marker on its coordinate (for an absolutely
positioned overlay, `transform: [{ translateX: '-50%' }, { translateY: '-50%' }]`)
and raise the active marker and the preview card above their neighbours.
Prices arrive formatted — the app owns currency and locale.

## `MapPriceMarker`

| prop                 | decides                                                                  |
| -------------------- | ------------------------------------------------------------------------ |
| `price`              | the text in the pill — SHORT: "€120", "€950/mo", "€240K", "€1.2M"         |
| `state`              | `'default'`, `'active'` (the open one) or `'visited'` (opened before)     |
| `size`               | `'default'` (28 tall) or `'compact'` (22 tall), for a dense map            |
| `saved`              | a small heart before the price                                           |
| `onPress`            |                                                                          |
| `accessibilityLabel` | a sentence — the pill shows only a number. Defaults to `price`           |
| `style`, `testID`    | the heart is `<testID>-saved`                                             |

A 28px full pill, `body-2-semibold` tabular text, 10px sides; `compact` is 22px
with `caption-1-semibold`, 8px sides and a 10px heart.

**Short prices.** The pill never truncates, so the app abbreviates: whole
currency under a thousand ("€168"), a rent with its period ("€950/mo"), sales in
thousands or millions ("€240K", "€1.2M"). Put the full price in
`accessibilityLabel` ("€240,000, Talmar Hill").

| state    | fill                    | label             | edge / elevation            |
| -------- | ----------------------- | ----------------- | --------------------------- |
| default  | surface (card; dark neutral-800) | text-primary | hairline, `shadow-s`; hover darkens the hairline |
| active   | text-primary (inverted) | card; dark neutral-900 | `shadow-m`             |
| visited  | neutral-100; dark neutral-900 | neutral-500; dark neutral-400 | hairline, `shadow-s` |

The heart is the theme's danger red. The marker is a `button` whose
`aria-pressed` (native `accessibilityState.selected`) is the active state.

## `MapClusterMarker`

`count` (number or a string like `"99+"`), `state` (`default` | `active`),
`onPress`, `accessibilityLabel` (default `"<count> stays"` — translate it),
`style`, `testID`. A 36px round bubble that widens for longer counts, painted
like the price pill.

## `MapAreaCircle`

| prop                 | decides                                                                  |
| -------------------- | ------------------------------------------------------------------------ |
| `radius`             | the radius in PIXELS — the app converts metres with its map projection and re-renders on zoom |
| `label`              | an optional pill at the centre ("~500 m", "Approximate area")            |
| `accessibilityLabel` | makes it an `img` with that name; without it the circle is decorative    |
| `style`, `testID`    | parts are `<testID>-fill`, `-edge`, `-label`                              |

The approximate location of a home whose address is private: a round
`2 × radius` box with the accent (`accent-500`; dark `accent-400`) as a fill
layer at 15% opacity and a solid 1.5px accent edge. The fill is a separate layer
at `opacity` rather than a colour with alpha, so the edge stays solid. The label
is a 24px surface pill with a hairline and `shadow-s`, `caption-1-semibold`.
It never takes a press (`pointerEvents="none"`), so the map keeps its gestures.
Centre it on the coordinate like a marker and draw it under the markers.

## `MapListingPreview`

| prop                 | decides                                                                  |
| -------------------- | ------------------------------------------------------------------------ |
| `image`, `imageVariant` | a URL, or an id for the app's `ImageResolver`                         |
| `title`              | one line, truncated                                                      |
| `rating`, `reviewCount` | handed to `Rating` (`null` draws "New"); omit `rating` to hide it     |
| `subtitle`           | the secondary line                                                       |
| `price`, `priceDetail`, `originalPrice` | "€150 **€120** night" — the original struck through   |
| `priceLines`         | stacked lines, as on `ListingCard`; replaces the three props above       |
| `facts`              | the facts row, as on `ListingCard`, 14px icons                           |
| `offerings`, `offeringLabels` | small tinted `OfferingBadge`s above the title                   |
| `favorite`, `onFavoriteChange` | the heart; shown only with the handler                         |
| `onClose`            | the close button; shown only with the handler                           |
| `onPress`            | opens the listing — the whole card is the target                         |
| `layout`             | `'vertical'` (photo on top, default) or `'compact'` (photo left, 112 wide) |
| `width`              | default `327`                                                            |
| `closeLabel`, `favoriteLabel`, `accessibilityLabel` | names; defaults "Close", "Save", `title` |

A 16-radius card on the floating surface (hairline, `shadow-m`). Vertical: a
200px photo, then 12px of padding around the title and `Rating` on one line,
the subtitle, and the price line. The close button is Bloom's `xs` secondary
icon button over the photo's top-left; the heart a 24px round button in the
opposite corner (compact: heart over the photo, close in the card's top-right).
The card never clips — the photo clips itself — so the native shadow survives.

The housing parts — offerings, price lines and facts — are the SAME components
`ListingCard` draws, at the body-2 size, so the preview and the card cannot
drift apart. With neither `price` nor `priceLines` there is no price line.

The open target is a button laid over the card BESIDE the close and heart
buttons rather than around them, so no button nests inside another. The heart
is a toggle with `aria-pressed` and native `accessibilityState.selected`.

## `MapSearchAreaButton`

`variant="toggle"` with `checked` / `onCheckedChange` draws a Bloom checkbox box
and "Search as I move the map" as a `checkbox` with `aria-checked`; the default
`variant="button"` with `onPress` draws a search icon and "Search this area".
Both take `label`, `disabled`, `style` and `testID`. A 40px floating pill on the
surface with a hairline and `shadow-m`; hover takes the menu hover fill.
