# ButtonGroup

A row of secondary-style buttons fused into one control: one bordered, shadowed container, items divided by 1px hairlines, only the outer ends rounded. The container is a full pill, like `Button`. Each item renders the platform's actual `Button` with `variant="secondary"`. Glass material, typography, hover, press, focus and disabled behavior therefore come from Button; the group only owns layout, seams and the outer shadow.

```tsx
import { ButtonGroup, ButtonGroupItem } from '@oxy.so/bloom/button-group';

<ButtonGroup accessibilityLabel="Alignment">
  <ButtonGroupItem onPress={alignLeft}>Left</ButtonGroupItem>
  <ButtonGroupItem onPress={alignCenter}>Center</ButtonGroupItem>
  <ButtonGroupItem onPress={alignRight}>Right</ButtonGroupItem>
</ButtonGroup>
```

## Selection

`selected` paints an item with its hover fill and announces it as pressed (`aria-pressed` on web, `accessibilityState.selected` on native). Drive it from state for single- or multi-select toolbars; leave every item unselected for a pure action row. For an animated thumb, use `SegmentedControl`.

```tsx
<ButtonGroup accessibilityLabel="Range">
  {ranges.map((range) => (
    <ButtonGroupItem key={range} selected={value === range} onPress={() => setValue(range)}>
      {range}
    </ButtonGroupItem>
  ))}
</ButtonGroup>
```

## Sizes and icons

| | medium | small |
|---|---|---|
| item height | 34 | 30 |
| padding-x | 12 | 10 |
| icon | 20 | 18 |

Text and icons follow Button's size geometry and typography. Pass icon components to `leadingIcon` / `trailingIcon`; `iconOnly` makes a square item that needs `accessibilityLabel`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `ButtonGroup.size?` | `'medium' \| 'small'` | `'medium'` | Size for every item. |
| `ButtonGroup.accessibilityLabel?` | `string` | — | Names the group. |
| `ButtonGroupItem.onPress?` | `() => void` | — | Press handler. |
| `ButtonGroupItem.selected?` | `boolean` | `false` | Hover fill + pressed state. |
| `ButtonGroupItem.disabled?` | `boolean` | `false` | Disabled paint, blocks presses. |
| `ButtonGroupItem.iconOnly?` | `boolean` | `false` | Square icon-only item. |
| `ButtonGroupItem.leadingIcon?` / `trailingIcon?` | `ComponentType<{ width, height, fill }>` | — | Icon components. |
| `ButtonGroupItem.size?` | `'medium' \| 'small'` | group size | Per-item override. |
