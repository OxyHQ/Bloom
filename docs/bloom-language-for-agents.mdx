# Bloom language for AI agents

Read this before writing language code. Everything below compiles (CI checks
the `check` blocks); the full lists are in the generated reference:
[nodes](bloom-language-nodes.mdx), [modifiers](bloom-language-modifiers.mdx),
[tokens](bloom-language-tokens.mdx). Installed apps have these pages at
`node_modules/@oxy.so/bloom/docs/`.

## The rules

1. **A view is a function that returns nodes.** `view(function Name(props) { return … })`.
   Hooks are allowed in the body. A route file default-exports
   `screen(function Name() { … })` or `layout(() => …)` from
   `@oxy.so/bloom-language/router`.
2. **Style is modifiers, chained; order is nesting.** `.padding('md').background('card')`
   fills the padding; `.background('card').padding('md')` pads outside the fill.
3. **Every value is a token string.** Never a number, a hex or a style
   object: `.padding('md')`, not `.padding(12)`; `.foreground('muted')`, not
   `'#666'`. Missing value: `defineTokens({ space: { gutter: 18 } })` and use
   `t.space.gutter`.
4. **Each node takes only its own modifiers plus the universal ones.** Look the
   node up in [the node reference](bloom-language-nodes.mdx) before chaining.
   `Text` has `.lines()`, stacks have `.spacing()` / `.align()` / `.justify()`.
5. **Inputs take bindings**: `[value, setValue]`, i.e. `useState(...)` itself.
6. **Presentation is a modifier on the trigger**: `.alert(binding, Alert(...))`,
   `.dialog(...)`, `.popover(...)`, `.sheet(open, () => content, { onDismiss })`.
7. **Text traits inherit** (`foreground`, `font`, `weight`, `leading`,
   `tracking`): set them on the stack, not on every `Text`.
8. **Icons are components**, imported one per file:
   `import { RiHeart3Line } from '@oxy.so/bloom/icons/RiHeart3Line'`, then
   `Icon(RiHeart3Line)`. An icon-only `Button`/`FAB` needs `.label('…')`.
9. **Glass is chrome**: headers, bars, floating controls. Not in lists, cards
   or scroll content; neighbours go in one `GlassGroup`; at most one tinted.
10. **Bloom-first**: if Bloom has the component, use its node; for anything
    else wrap the element: `Embed(<Thing />)`. No `className`, no `style`,
    no NativeWind.

## Imports

The root, `@oxy.so/bloom-language`, is the language: its layout, text, media and navigation views,
modifiers and values. Each family of nodes is an entry of its own, `@oxy.so/bloom-language/<family>`
(`/inputs`, `/list`, `/containers`, `/overlays`, `/chart-cards`…), so an app's bundle carries only the
families it imports. The reference names each node's module ([nodes](bloom-language-nodes.mdx)); the
codemod writes these imports.

## A screen, complete

```tsx check
import { useState } from 'react';
import { Button, HStack, Icon, ScrollView, Spacer, Text, VStack } from '@oxy.so/bloom-language';
import { Field, TextField, Toggle } from '@oxy.so/bloom-language/inputs';
import { ListItem } from '@oxy.so/bloom-language/list';
import { navigate, screen } from '@oxy.so/bloom-language/router';
import { RiAddLine } from '@oxy.so/bloom/icons/RiAddLine';

interface Item { id: string; title: string; detail: string }

export default screen(function Items() {
  const [items, setItems] = useState<Item[]>([]);
  const title = useState('');
  const urgent = useState(false);
  const [adding, setAdding] = useState(false);
  const add = () => {
    setItems((all) => [...all, { id: String(all.length + 1), title: title[0], detail: urgent[0] ? 'Urgent' : 'Later' }]);
    setAdding(false);
  };
  return ScrollView(
    items.length === 0 ? Text('Nothing yet').foreground('muted').padding('lg') : null,
    items.map((item) => ListItem(item.title).supporting(item.detail).onPress(navigate('/items/[id]', { id: item.id })).id(item.id)),
  )
    .title('Items')
    .toolbar(Button(Icon(RiAddLine)).label('Add item').onPress(() => setAdding(true)))
    .sheet(
      adding,
      () =>
        VStack(
          Field('Title', TextField(title, 'Title')),
          HStack(Text('Urgent'), Spacer(), Toggle(urgent).label('Urgent')),
          Button(Text('Add')).disabled(title[0] === '').onPress(add),
        )
          .spacing('md')
          .padding('lg'),
      { onDismiss: () => setAdding(false) },
    );
});
```

## Common mistakes

| Wrong | Right | Why |
| --- | --- | --- |
| `.padding(12)` | `.padding('md')` | tokens only |
| `.foreground('#888')` | `.foreground('muted')` or an app colour token | colours are roles |
| `.font('footnote')` | `.font('caption-1')` | the ramp's names ([font](bloom-language-tokens.mdx#font)) |
| `count && Text(count)` | `count ? Text(String(count)) : null` | 0 would draw a bare `0` |
| `HStack(a, b).lines(1)` | `Text(…).lines(1)` | `lines` is `Text`'s |
| `Button(Icon(X))` | `Button(Icon(X)).label('Share')` | icon-only needs a label (compile error) |
| `Button(…).size('medium')` | `Button(…).size('md')` | node token set ([controlSize](bloom-language-tokens.mdx#controlsize)) |
| `Avatar(src).size('2xl')` | `.size('xl')` | avatar rungs are `xs` `sm` `md` `lg` `xl` |
| `TextField(value, …)` | `TextField([value, setValue], …)` | a binding, not a value |
| `<Pressable>` around a node | `.onPress(fn)` | presses are modifiers |
| `.onPress(() => router.push('/x'))` | `.onPress(navigate('/x'))` | the panel-aware navigator |
| `<Link asChild>` around a span in a text | `Embed((render) => <Link href={h} asChild>{render(Text(…))}</Link>)` as a run | the Link hands the span's host its href and press |
| `.plainRun((t) => Text(...linkify(t)))` | `.plainRun(linkify)` returning strings and spans | runs, no extra span around the prose |
| `<Screen>` in one branch of a `screen()`, a call surface in another | `CallScreen(…).ownScreen()` in that branch, `null` for nothing | `screen()` draws a Screen around every other branch |
| `cond ? list : <Provider value={v}>{list}</Provider>` | `.provider(cond ? undefined : Provider, { value: v })` on the root | a screen's providers are modifiers |
| `.when('hover', …)` | `.when('hovered', …)` | condition names |
| `.when('md', v => v.onPress(…))` | handlers outside `when()` | variants change style only |
| `.opacity('half')` on a glass | no opacity on glass | a material is never faded |
| `ZStack(a, b.alignment('top-leading'))` | `ZStack(a, b).alignment('top-leading')` or `.overlay(b, 'top-leading')` | alignment is the stack's |
| a new arrow as `VirtualList`'s row each render | a `useCallback` or module-scope row | rows re-render only when their item changes |
| Bloom's JSX `<VirtualList renderItem={() => toElement(row)}>` | `VirtualList(items, row)` in the language | a language row has no boundary of its own (a component and a context read less per row) |
