# 6.2.1

Patch backport of the native bottom-sheet dismissal fix from `efa54000221298f95006815d1ab087647b563e4c` (7.x, PR #258) onto published 6.2.0. No 7.x API removals or migration are included.

A vetoed Android Back or pan request now leaves the sheet open. Explicit close/X completes once and notifies its owner, allowing the dialog to reopen instead of leaving a pending result after the visible surface disappears. The existing `onDismissAttempt` contract applies before user dismissal; imperative close completes without that veto.

The dismissal backport initially copied six runtime/test/contract files byte-for-byte from the accepted upstream fix. A separate one-line surface correction restores the themed default dialog fill, with light/dark SVG paint regressions and an explicit-transparent control. Local validation: six focused suites/82 tests, TypeScript plus isolated consumer control, CJS/ESM/types build and package/freshness gates. Device candidate acceptance is recorded separately. This patch does not claim to fix the separate native touch observation.
