# Bloom

Shared UI component library for the Oxy ecosystem. Built for React Native + Expo + Web.

<Badge>Breathe License 1.0</Badge>

## Install

```sh
bun add @oxy.so/bloom
```

### Peer dependencies

Required:

- `react >= 18`
- `react-native >= 0.73`
- `react-native-safe-area-context >= 5`

Also required:

- `react-native-reanimated >= 3.13` (`Dialog`, `BottomSheet`, `toast`, `Loading`) — on web too
- `react-native-gesture-handler >= 2.16.1` (`Dialog`, `BottomSheet`, toast swipe-to-dismiss) — native also needs the app root wrapped in `GestureHandlerRootView`
- `react-native-svg >= 13` (Bloom icons, all non-circular Avatar shapes)

## What's inside

Bloom ships an app shell and navigation, overlays, form controls, data tables and dashboard charts, AI and agent interfaces, notifications, typography, theming and a Remix icon set, with shared native/web contracts and documented platform-specific rendering and interaction limits. Everything is exported under a sub-path (`@oxy.so/bloom/dialog`, `@oxy.so/bloom/button`, etc.) so tree-shaking stays effective.
