# Migrating to 9.0

Bloom follows its clean-cut rule: no `@deprecated` aliases, no shims. A symbol that was removed or renamed is simply gone, and the build tells you. This page lists every one, grouped by the change that caused it.

## The short version

1. Install `@oxy.so/bloom@^9.0.0`. Remove `expo-glass-effect` from your app if nothing else uses it.
2. Rename control sizes `small` / `medium` / `large` to `sm` / `md` / `lg` (TypeScript lists every site).
3. `AlertDialog` and `Command`: `visible` + `onClose` become `open` + `onOpenChange`.
4. `ComposerPill` / `ComposerPanel`: `listening` becomes `voiceState`.
5. Rename the `glass*` props and tokens in the table below.

Additive in 9.0, nothing to migrate: `Markdown`, `AgentLogToolCall` / `AgentLogToolCalls` (tool calls as log lines), `AgentThinking` children + `thinking` + `durationMs` (the collapsible "Thought for N s"), `AgentProgressPlan` (Approve / Reject on the progress card), `AudioWaveVisualizer` / `VoiceControls` / `VoiceOverlay`, attachments / `error` / disabled add-menu rows on `ComposerPill`, `EmptyState` `suggestions`, and the `agent`, `reasoning`, `toolCalls` and `markdown` fields on `AgentChat` messages.

## The surface material is blur and tint

`Surface`, `Button`, `Card`, `Sidebar` and every painted overlay share one material. It no longer has a refraction layer.

| Before | After |
|---|---|
| Web: backdrop blur plus an SVG displacement filter (`feTurbulence` / `feDisplacementMap`) on every painted surface. | Web: one `backdrop-filter: blur(8px)`. No SVG filter. |
| Native: an `Svg` tree per surface (tint rect, sheen gradient, rim view) with `onLayout` state. | Native: one `View` — tint as `backgroundColor`, sheen as `experimental_backgroundImage`, rim as an inset `boxShadow`. |
| `useSurfaceRefraction`, `ensureSurfaceRefraction`, `SURFACE_REFRACTION_ID`, `surface/web-refraction` | Removed. Nothing to replace. |
| `surfaceSvgStop`, `SURFACE_SHEEN` (the stop array) | Removed. `SURFACE_SHEEN_CSS` is the one sheen string. |

Native surfaces have no per-surface blur: a `BlurView` inside its own blur target can crash Android. Native blur lives in the overlay `Backdrop` and `ProgressiveBlur`.

## Glass names are gone

| Before | After |
|---|---|
| `GlassIsland` (internal) | `BlurIsland` |
| `GlassBlurTargetProvider`, `GlassBlurWindow` (internal) | `BlurTargetProvider`, `BlurWindow` |
| `TabBarTheme.glassTint` | `TabBarTheme.blurTint` |
| `ComposerPill glass` | `ComposerPill frosted` |
| `ThemeToggle variant="glass-segmented"` | `variant="bare-segmented"` |
| `Card elevation="glass"`, `bloomShadowStyle('glass')`, `SHADOW_BOX.glass`, Tailwind `shadow-glass` | `'floating'` |
| `SURFACE_SHAPES.glass` (design token `shapes.glass`) | `SURFACE_SHAPES.island` (`shapes.island`) |

## The tab bar has no liquid-glass capsule

`TabBar` paints the same capsule material on every platform. `expo-glass-effect` is no longer a peer or a dependency; remove it from your app if nothing else uses it. `TabBarGlassFallback`, `GlassView` and the `solidFallback` logic are gone.

## One size vocabulary

`small` / `medium` / `large` are gone from control sizes. The geometry is unchanged: rename the value.

| Component | Before | After |
|---|---|---|
| `Badge` | `small` / `medium` / `large` (`label-small`, `label-medium` stay) | `sm` / `md` / `lg` |
| `Chip`, `Sidebar` | `small` / `medium` / `large` | `sm` / `md` / `lg` |
| `Rating`, `OfferingBadge`, `EnergyBadge`, `ExplicitBadge`, `UnreadBadge`, creator-studio, chat-people | `small` / `medium` | `sm` / `md` |
| `PresenceDot` | `small` / `medium` / `large` | `sm` / `md` / `lg` |

Content-density types keep their words: `MediaCard`, `Lyrics`, `ListingHeader`, `ListingSection`, `ShipmentLoadSize` and `TileSize` describe a layout or a load, not a control.

## One open / close pair on declarative overlays

| Component | Before | After |
|---|---|---|
| `AlertDialog` | `visible` + `onClose()` | `open` + `onOpenChange(open)` |
| `Command` | `visible` + `onClose()` | `open` + `onOpenChange(open)` |

`onOpenChange` is called with `false` on every close. `Dialog`, `SettingsModal` and `BottomSheet` keep their imperative `control` / ref contract: a controlled boolean races the exit animation there (`docs/dialog.mdx`).

## Composer

`ComposerPill` and `ComposerPanel` share one voice contract. The `listening` boolean is replaced by a three-state `voiceState`, so a recording that is being transcribed is no longer indistinguishable from one still running.

| Before | After |
|---|---|
| `listening` | `voiceState` (`'idle'` \| `'recording'` \| `'transcribing'`) |
| `defaultListening` | `defaultVoiceState` (default `'idle'`) |
| `onListeningChange(listening)` | `onVoiceStateChange(voiceState)` — reports `'recording'` or `'idle'` |

`listening={true}` becomes `voiceState="recording"`; `onListeningChange={(on) => ...}` becomes `onVoiceStateChange={(s) => ... s === 'recording'}`. Entering `'transcribing'` is yours to do, after the recorder stops. `MicButton`'s internal `listening` prop is `state` with a required `transcribingLabel`; it is not part of the public API.

Additions, not breaks: `ComposerPill` takes `attachments`, `onRemoveAttachment`, `onAttachmentRetry` and `error`; add-menu rows take `disabled`; `labels` gains `transcribing` (and `remove`, `retry` on the pill); `EmptyState` takes `suggestions` and `suggestionsLabel`.
