# Bloom language tokens

Every value a modifier takes is a token of a named set: a Bloom rung, never a pixel or a colour. A numeric token (`'44'`) is an exact value apps write, named by its value. An app adds its own space, size, leading, motion and colour tokens with `defineTokens` ([tokens in the tour](bloom-language-tour.mdx#tokens)). The sets below are the ones the compiler checks a literal against (281); where the spec gives a token a value (points, a colour role's theme key and CSS variable, a motion's timing) it is shown.
