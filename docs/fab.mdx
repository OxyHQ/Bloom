# Fab

A floating button for the **one** thing a screen is mostly for: compose on a
feed, add on a list, new message in an inbox.

```tsx
import { Fab } from '@oxy.so/bloom/fab';

<Fab
  icon={<PencilIcon />}
  accessibilityLabel="New post"
  onPress={compose}
/>

<Fab
  icon={<PencilIcon />}
  label="New post"
  placement="bottom-right"
  onPress={compose}
/>
```

## Which prop decides what

| prop               | decides                                                    |
| ------------------ | ---------------------------------------------------------- |
| `icon`             | the glyph                                                   |
| `label`            | makes it an extended FAB with visible text                  |
| `variant`          | `primary` · `secondary` · `tertiary` · `surface`            |
| `size`             | `small` · `medium` · `large`, or a number                   |
| `placement`        | which corner it floats in, or `static` to place it yourself |
| `offset`           | distance from the edges                                     |
| `minimizeBehavior` | `none` · `hide` · `collapse` with the nearest Bloom tab bar |

## An icon-only FAB needs `accessibilityLabel`

Without it the button announces as "button" and nothing else. A pencil is not
self-describing to a screen reader, and it is not always self-describing on
screen either — which is what `label` is for.

## One per screen

A FAB claims the corner and floats above the content. Two of them are two
primary actions, which means neither is primary, and they compete for the same
thumb position. If a screen has several important actions, the FAB takes the
most common one and the rest go in the content or a menu.

On web, a bottom placement stays inside the content column with sticky
positioning. The column must fill the available height, use flex-column layout,
and render the FAB last. This keeps it at the bottom with short content and in
view while the document scrolls, without escaping over a side rail. Top
placements remain absolute within their positioned container.

## Following a Bloom tab bar

The FAB automatically clears the bottom-edge footprint claimed by Bloom's tab
bar and follows its compact height when it minimizes. An extended FAB can also
react to that state:

```tsx
<Fab label="Compose" minimizeBehavior="collapse" {...props} />
<Fab label="Compose" minimizeBehavior="hide" {...props} />
```

`collapse` smoothly retracts the label and horizontal space while retaining the
icon-only action. `hide` removes the whole action. The default is `none`, which
preserves the full FAB.

## `placement="static"` when something else owns the position

A FAB inside a custom positioned container can use `static` to turn off Bloom's
anchoring. Do not use it merely to avoid a Bloom tab bar; bottom-edge clearance
and `minimizeBehavior` already cover that case.
