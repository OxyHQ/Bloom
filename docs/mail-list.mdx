# Mail lists

Use `List` and `ListItem` from `@oxy.so/bloom/list`.

```tsx
<ListItem
  mail={{sender:{name:'Mireia'},subject:'Roof survey',snippet:'Measurements attached',
    time:'14:02',unread:true,labels,onStarredChange:setStarred,starred}}
  href="/messages/roof"
  checked={checked}
  onCheckedChange={setChecked}
  actions={commands}
  swipeActions={swipeCommands}
  attachments={<><Chip onPress={openFile}>survey.pdf</Chip></>}
/>
```

The mail recipe retains sender, subject, snippet, draft wording, attachment
indicator, thread count, labels and overflow, unread emphasis and the star.
Subject and snippet share one Text node so truncation cannot push the subject
out of the row. Unread changes text weight and contrast; it is not conveyed by
colour alone. Times and addresses arrive formatted by the app.

Selection, menus, swipe bubbles and layout are shared with every other ListItem.
The avatar changes to a checkbox only when selected, hovered or focused.
The star, footer controls and attachments are siblings of the navigation target.
Pass file chips directly to `attachments`; the common row owns the rail and inset.

`groupMailByDay` remains a pure grouping helper in `@oxy.so/bloom/mail-list`.
Map each returned bucket to a List section and its messages to `mail` display data.
Use the shared `ListSelectionBar` for bulk actions. Permission filtering, checked
IDs, navigation, network operations and destructive-action confirmation belong
to the consumer.

The actual browser hit-testing regression gate is
`scripts/verify-mail-row-pointer.mjs`: synthetic element.click() cannot reveal
foreground layout layers intercepting the absolute navigation target.
See [List](./list.mdx) for the complete shared interaction contract.
