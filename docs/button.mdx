# Button

The all-purpose Bloom button. Variants for primary/secondary/ghost/destructive actions plus inverse/icon/text/link, four sizes, loading state, sized icon components, and full accessibility props.

Both forks read ONE table — `src/button/shared.ts` — for geometry and every state's colours, so native and web cannot drift apart.

## Basic

```tsx
import { Button } from '@oxy.so/bloom';

<Button onPress={save}>Save</Button>
```

## Variants

```tsx
<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="ghost">Ghost</Button>
<Button variant="destructive">Delete</Button>
<Button variant="inverse">Inverse</Button>
<Button variant="text">Text</Button>
```

| Variant | Paint |
|---|---|
| `primary` | Top-to-bottom gradient of `primary` (500 → 600). Hover lightens it (400 → 500), press deepens it (600 → 700). Label `primaryForeground`. xs drop shadow. |
| `destructive` | The same recipe on `negative` / `negativeForeground`. |
| `secondary` / `outline` | `card` surface, 1px `border`, `text` label, xs drop shadow; hover/press step the surface and border toward the label colour. |
| `ghost` | The `primarySubtle` tint with its `primarySubtleForeground` label — the policy's own legibility-checked pair; hover/press deepen the tint. |
| `icon` | `secondary`'s surface as a fixed square (border included), glyph 20 / 16 at medium / small; disabled dims the whole control to 0.6. |
| `inverse` | White surface, black label — for use over media. |
| `text` | Borderless `primary` label on a compact 4/8 padding with a hover wash (Bloom-only). |
| `link` | No container at all — label only, `accent-600` (`linkTone="secondary"`: secondary text), underline (offset 3) on hover, `accent-800` while held. |

The accent and neutral ramps are rebuilt around the theme colours in OKLCH (`button/shared.ts`), since Bloom presets carry one `primary` rather than a Tailwind ramp. There is NO press scale — a press is the active paint alone — and disabled buttons take their own paint instead of an opacity dip (`icon` excepted).

On web the state colours arrive as `--bloom-btn-*` custom properties and are declared only in the adopted stylesheet — an inline `background-color` would silence the `:hover` rule. The gradient variants cross-fade their hover gradient in through `::before`, because `background-image` does not transition. On native the gradient is a `react-native-svg` layer; every gradient stop is an opaque composite, since react-native-svg drops alpha in `stopColor`.

## Sizes

```tsx
<Button size="xs">Xs</Button>
<Button size="small">Small</Button>
<Button size="medium">Medium</Button>
<Button size="large">Large</Button>
```

| | xs | small | medium | large |
|---|---|---|---|---|
| height | 24 | 32 | 36 | 44 |
| radius | full pill | full pill | full pill | full pill |
| padding-x | 8 | 8 | 8 | 12 |
| gap | 2 | 2 | 2 | 2 |
| icon | 14 | 18 | 20 | 20 |
| text (`TYPE_SCALE`, Inter) | `caption-1-semibold` | `body-medium` | `body-medium` | `headline-medium` |
| icon-only | 24 × 24 | 32 × 32 | 36 × (36 + 2 × border) | 44 × 44 |

`large` extends the ramp to the 44 dp touch floor. Bloom keeps every button-like control a full pill. Height is fixed and the label's line box is centred inside it, so a bordered variant measures the same as a filled one. A medium icon-only button is NOT forced square — its width is content (8 + 20 + 8) plus the border, so a `secondary` one is 38 × 36; small and xs are forced squares. `text` / `link` drop the fixed height on web so the control hugs its label and sits inline.

Native adds vertical `hitSlop` to bring every size up to a 44 dp touch target; horizontal slop is zero, so two buttons in a row cannot steal each other's presses. On web `hitSlop` does not exist and the target is the box.

## Loading

```tsx
const [busy, setBusy] = useState(false);

<Button
  loading={busy}
  onPress={async () => {
    setBusy(true);
    try { await submit(); } finally { setBusy(false); }
  }}
>
  Submit
</Button>
```

When `loading` is true, a centered spinner appears, children stay in the layout (hidden) so width doesn't jump, presses are blocked, and the button keeps its resting paint. `loadingColor` overrides the spinner color (defaults to the label color).

## With icons

Pass icon COMPONENTS, not elements — the button sizes and colours them for the current size and state:

```tsx
import { RiAddLine, RiArrowRightLine } from '@oxy.so/bloom/icons';

<Button leadingIcon={RiAddLine}>New</Button>
<Button leadingIcon={RiAddLine} trailingIcon={RiArrowRightLine}>Both sides</Button>
<Button iconOnly leadingIcon={RiAddLine} accessibilityLabel="New" />
```

Use Remix icons (`RiAddLine`, `RiArrowRightLine`, `RiDeleteBinLine`…). `iconOnly` renders the icon-only shape from the table above and drops the label — name it with `accessibilityLabel`. `icon` takes either a component (sized like `leadingIcon`) or a pre-rendered node, which the button does not size.

## IconButton, LinkButton, CloseButton

Three companions to `Button`, exported from the same family:

```tsx
<IconButton icon={RiMore2Line} accessibilityLabel="More" />          // 36, glyph 20
<IconButton icon={RiMore2Line} size="small" accessibilityLabel="More" /> // 32, glyph 16

<LinkButton trailingIcon={RiArrowRightSLine}>Browse components</LinkButton>
<LinkButton variant="secondary" href="/docs">Docs</LinkButton>

<CloseButton size="md" accessibilityLabel="Close" onPress={close} />
```

- `IconButton` is `<Button variant="icon">` and still accepts every `Button` prop (existing call sites keep working).
- `LinkButton` is `<Button variant="link">`; its `variant` is the link COLOUR (`primary` | `secondary`). Sizes medium / small / xs use `body-medium` / `body-medium` / `caption-1-semibold` with 20 / 18 / 14 icons and a 4px gap.
- `href` (any `Button`) renders a real `<a href>` on web and drops the `href` while disabled; on native a press opens the URL unless `onPress` is set.
- `CloseButton` is a round `background/tertiary` disc (16 / 20 / 24 / 32) with a two-stroke X drawn per size in its own viewBox, so the stroke is a literal pixel value (1.6 / 2 / 2 / 2.5); the glyph turns `text/primary` on hover (held press on native). The control draws no text, so `accessibilityLabel` is required.

## Disabled

```tsx
<Button disabled>Can't click me</Button>
```

`disabled` blocks presses and switches to the variant's disabled paint.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `onPress?` | `() => void` | — | Press handler. |
| `children?` | `React.ReactNode` | — | Button label. Strings are auto-wrapped in `Text`. |
| `disabled?` | `boolean` | `false` | Blocks presses, disabled paint. |
| `variant?` | `'primary' \| 'secondary' \| 'ghost' \| 'destructive' \| 'outline' \| 'inverse' \| 'icon' \| 'text' \| 'link'` | `'primary'` | Visual style. |
| `size?` | `'xs' \| 'small' \| 'medium' \| 'large'` (+ `sm \| md \| lg \| icon`) | `'medium'` | Height, radius, padding, type and icon size. |
| `leadingIcon?` | `ComponentType<{ width, height, fill }>` | — | Icon component before the label, sized by the button. |
| `trailingIcon?` | `ComponentType<{ width, height, fill }>` | — | Icon component after the label. |
| `iconOnly?` | `boolean` | `false` | Square icon-only button. |
| `icon?` | `React.ReactNode \| ComponentType` | — | Icon component (sized) or pre-rendered node next to the label. |
| `linkTone?` | `'primary' \| 'secondary'` | `'primary'` | Colour of the `link` variant. |
| `href?` | `string` | — | Renders an anchor on web; opens the URL on native. `target` / `rel` pass through on web. |
| `iconPosition?` | `'left' \| 'right'` | `'left'` | Which side of the label `icon` goes. |
| `loading?` | `boolean` | `false` | Show centered spinner, block presses. |
| `loadingColor?` | `string` | label color | Override the spinner color. |
| `style?` | `StyleProp<ViewStyle>` | — | Outer container style. |
| `textStyle?` | `StyleProp<TextStyle>` | — | Label style. |
| `accessibilityLabel?` | `string` | — | Required for icon-only buttons. |
| `accessibilityHint?` | `string` | — | |
| `hitSlop?` | `{ top, bottom, left, right }` | — | Expand the touch target. |
| `testID?` | `string` | — | RN testing id. |
| `className?` | `string` | — | NativeWind class. |

## Recipes

### Destructive confirmation

```tsx
<Button variant="destructive" onPress={destroy}>
  Delete forever
</Button>
```

For most destructive actions, prefer a `<Dialog>` with `color: 'destructive'` actions over a destructive button in the main flow.

### Submit button with promise

```tsx
const [busy, setBusy] = useState(false);

<Button
  loading={busy}
  onPress={async () => {
    setBusy(true);
    try { await save(form); toast.success('Saved'); }
    catch (err) { toast.error(extractErrorMessage(err)); }
    finally { setBusy(false); }
  }}
>
  Save changes
</Button>
```

### Icon button row

```tsx
<View style={{ flexDirection: 'row', gap: 4 }}>
  <Button variant="secondary" iconOnly leadingIcon={RiBold} accessibilityLabel="Bold" />
  <Button variant="secondary" iconOnly leadingIcon={RiItalic} accessibilityLabel="Italic" />
  <Button variant="secondary" iconOnly leadingIcon={RiLink} accessibilityLabel="Link" />
</View>
```
