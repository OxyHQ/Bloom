# FrostedIconButton

`FrostedIconButton` composes the shared Button material. Its historical name no longer selects a separate blur engine: the default is the same opaque fill, sheen and rim as other buttons.

```tsx
import { FrostedIconButton } from '@oxy.so/bloom/frosted-icon-button';

<FrostedIconButton icon={CloseIcon} accessibilityLabel="Close" onPress={close} />
```

Sizes `xs`, `sm`, `md`, `lg` draw 28, 32, 36, 44px circles; a number sets an exact diameter. Icon size follows the existing geometry. Size and tone inherit from BloomScope. The unchecked state is neutral; checked uses the selected semantic tone and exposes `aria-pressed` on web and selected accessibility state on native.

`onCheckedChange` receives the next boolean; `onPress` also runs when supplied. Web additionally calls `onClick`. Disabled controls call none of them. Caller style, className, native hitSlop, accessibility name and web form props remain on the actual Button root.

The native and web entry points bind the same adapter to their respective Button implementation. No extra layout wrapper, per-control blur, animated scale, palette or interaction stylesheet remains. Keeping className on the parent-laid-out root avoids the former native layout bug where an animation wrapper absorbed sizing utilities.
