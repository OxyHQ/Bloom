## Compose a document workspace

Search: document, database, inspector, continuous workspace. Status: **recommended**.

Choose joined panels for one continuous workspace; choose separated panels when each region needs its own frame.

```tsx
import { AppShell } from '@oxy.so/bloom/app-shell';
import { PageHeader } from '@oxy.so/bloom/page-header';
import { Screen, ScreenScrollView } from '@oxy.so/bloom/screen';
```

Runnable component: [workspace.tsx](./examples/workspace.tsx). Story: `blocks-app-shell--continuous-workspace` (`ContinuousWorkspace`).

Canonical guides: [compose-layouts](./compose-layouts.mdx), [app-shell](./app-shell.mdx), [screen](./screen.mdx), [page-header](./page-header.mdx).

- **state:** Application owns data, navigation, permissions and persistence. Stable panel IDs preserve UI identity.
- **scroll:** AppShell bounds the viewport; each Screen owns its region. ScreenScrollView binds to that owner.
- **surface:** The shell/panel and shared controls own their material. Do not add a second panel surface.
- **focus:** Use shared controls and overlay owners; do not move focus as a layout side effect.
- **motion:** Shared owners animate; applications supply discrete state rather than per-frame React updates.
- **keyboard:** Screen and its footer coordinate the visible viewport; the shared input/composer owns editing and IME. Do not add keyboard-height compensation in the route.

Avoid: Do not wrap each descriptor in another panel or AppShell. Keep md controls; domain density is separate.

Consumer context: Nilo: apps/app/components/shell/nilo-shell.tsx; published pilot acceptance pending.

Runtime evidence for this example: web **not run**, Android **not run**, iOS **not run**. Catalog example runtime acceptance is separate from source/type/export validation. No physical iPhone claim.

## Host a map or interactive canvas

Search: map, board, canvas, persistent panel. Status: **variant**.

```tsx

import { Text } from '@oxy.so/bloom/typography';
import { AppShell } from '@oxy.so/bloom/app-shell';
import { PageHeader } from '@oxy.so/bloom/page-header';
import { Screen } from '@oxy.so/bloom/screen';
```

- **state:** Application owns data, navigation, permissions and persistence. Stable panel IDs preserve UI identity.
- **scroll:** Screen scroll=none reserves the viewport; the domain canvas owns its gestures. MapControls supplies callback-driven controls, not a scroller or map engine.
- **surface:** The shell/panel and shared controls own their material. Do not add a second panel surface.
- **focus:** Use shared controls and overlay owners; do not move focus as a layout side effect.
- **motion:** Shared owners animate; applications supply discrete state rather than per-frame React updates.
- **keyboard:** Screen and its footer coordinate the visible viewport; the shared input/composer owns editing and IME. Do not add keyboard-height compensation in the route.

Avoid: This minimal example does not implement occupied map regions or a persistent non-modal sheet. Do not substitute a modal Dialog for that missing contract.
