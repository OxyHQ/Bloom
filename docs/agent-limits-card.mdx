# AgentLimitsCard — deprecated

Use [UsageCard](./usage-card.mdx) from `@oxy.so/bloom/usage-card`.
The old component and all AgentLimits types remain compatible but deprecated.
There is one shared implementation for layout, color, and motion.

| Deprecated | Canonical |
| --- | --- |
| AgentLimitsCard / AgentLimitsCardProps | UsageCard / UsageCardProps |
| AgentLimitsCardLabels | UsageCardLabels |
| AgentLimitsContext | UsageData |
| AgentLimitsContextSegment | UsageSegment |
| AgentLimitsContextGroup | UsageGroup |
| AgentLimitsUsageLimit | UsageLimit |

Rename `context` to `usage`, `tokens` to `value` (also within groups/items),
`formatTokens` to `formatValue`, and `labels.contextWindow` to `labels.usage`
or `title`. Pass `radius="radius-16"` to retain the legacy radius;
UsageCard defaults to radius28. The compatibility adapter preserves the
localized Context window heading and radius16 automatically.

```tsx
import { UsageCard } from '@oxy.so/bloom/usage-card';

<UsageCard title="Context window" radius="radius-16"
  usage={{ max: 1_000_000, segments: [{ label: 'Messages', value: 520_000 }] }}
/>
```
