# ConversationSidebar

The sidebar of a chat app that has agents: the account's conversations, each drawn with the avatars of who is in it. It is [`Sidebar`](./sidebar.mdx) with its destination content and header filled in, so the panel's own footer (account, settings, plan) is yours through the same props.

```tsx
import { ConversationSidebar } from '@oxy.so/bloom/conversation-sidebar';

<ConversationSidebar
  conversations={chats.map((chat) => ({
    id: chat.id,
    title: chat.title,
    description: chat.lastMessage,
    agents: chat.agents, // AgentReplyAgent[]: id, name, avatar
    pinned: chat.pinned,
  }))}
  activeId={activeId}
  onSelect={open}
  query={query}
  onQueryChange={setQuery}
  onMarketplace={() => router.push('/agents')}
  createOptions={[
    { key: 'agent', label: 'Create an agent', leading: <AgentAvatar … />, onPress: createAgent },
    { key: 'team', label: 'Chat with your agents', leading: <AgentStack … />, onPress: pickTeam },
  ]}
  actions={(chat) => [
    { key: 'pin', label: chat.pinned ? 'Unpin' : 'Pin', icon: RiPushpinLine },
    { key: 'delete', label: 'Delete', icon: RiDeleteBinLine, destructive: true },
  ]}
  onAction={(chat, key) => run(key, chat)}
/>
```

## What it draws

| Part | Props |
| --- | --- |
| **Three tools** on top | search (always; `query` / `onQueryChange`, `searchOpen` / `onSearchOpenChange`), the store button (`onMarketplace`), and the "+" menu (`createOptions`). Each of the last two is absent without its prop. |
| **Rows** | `conversations`: `title`, `description`, `agents` (stacked as the avatar; one agent is drawn larger) and `pinned` (a pin). `activeId` selects one; `onSelect` opens it. |
| **Context menu** | `actions(conversation)` returns a menu per row (right-click, long press); `onAction(conversation, key)` runs it. A `destructive` action is drawn as one. No actions, no menu. |
| **Words** | `labels`: every string defaults to Bloom's localized copy. |
| **Under the rows** | `after`: a loading line or ghost rows while another page arrives (with it, the "no conversations" text is not drawn). |
| **The panel** | every other `Sidebar` prop (`items`, `tree`, `secondaryItems`, `team`, `footer`, `mobile`, `className`, `style`, `onScroll`…) goes straight through. It has no look of its own beyond `Sidebar`'s: a card, a width, a border are yours to give. |

The sidebar does not filter, sort or group: the list you pass is the list it draws, so the order is yours (pinned first, newest first) and `query` only reports what was typed.

## Platform

`Dropdown` and `ContextMenu` are platform-forked, so the family is too: the native and web entries hand the right ones to the same single-source body. [`MultiAgentChat`](./multi-agent-chat.mdx) uses this sidebar for its conversations.
