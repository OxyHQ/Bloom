# Reasoning

A header and a body. The header reads "Thought for 12 s" once the model is done and shows the `AgentThinking` indicator and shimmering label while it is still reasoning. The body, text or nodes, opens and closes under it.

```tsx
import { Reasoning } from '@oxy.so/bloom/reasoning';

<Reasoning streaming={isStreaming} durationMs={elapsedMs}>
  {reasoningText}
</Reasoning>
```

## Props

| Prop | Type | Default | |
| --- | --- | --- | --- |
| `children` | `ReactNode` | | A string is drawn as secondary body text; any node is drawn as is. A string that grows as tokens arrive is fine. |
| `streaming` | `boolean` | `false` | Header shows the thinking indicator; the body opens. |
| `durationMs` | `number` | | Finished header: "Thought for 12 s". |
| `open`, `defaultOpen`, `onOpenChange` | | `defaultOpen` is `streaming` | Controlled or uncontrolled. |
| `size` | `'sm' \| 'md' \| 'lg'` | `BloomScope`'s, then `md` | Sizes the header button and the body text. |
| `className`, `style`, `testID`, `ref` | | | The root. The header is `<testID>-header`, the body `<testID>-body`. |

## Streaming

Opening and closing follow `streaming` until the user takes over:

- A stream that starts opens the body; one that ends closes it. The change is reported through `onOpenChange` like any other, so a controlled parent sees it.
- A press on the header settles the state for the rest of that stream. Close it mid-stream and it stays closed when the stream ends; open it after and it stays open.
- The next stream starts open again.

Mounting with `streaming` already true starts open and reports nothing.

## Duration

`durationMs` is rounded to whole seconds and read with the locale's units, `1 min 5 s` once it passes a minute, and a whole minute drops the seconds. Under half a second reads "Thought for a moment". Without `durationMs` the finished header reads "Reasoning". Every string is localised via `BloomProvider locale`.

## Accessibility and platforms

- **The header is `Button`**: a real `<button>` on web with `aria-expanded`, press feedback and focus ring from the button. While streaming the indicator's timer is off, so the button's name does not tick.
- **Reduced motion** is the Collapsible's and the indicator's: the body settles without animating and the shimmer drops.
- **RTL**: the rule beside the body is a logical inset, and the root forwards the document direction, so it mirrors.
