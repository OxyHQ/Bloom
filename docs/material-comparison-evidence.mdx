The fixture pins React 19.3.0, RN 0.88.1, Expo 58.0.23, react-native-svg 15.16.0,
expo-blur 58.0.5, Reanimated 4.7.1 and Worklets 0.13.0. React Compiler is disabled.
The native Bloom module is the published 17.22.0 dependency; JavaScript imports
the checkout source. The lock and build manifest record the rest of the graph.

Both successful Android starts passed the final-APK no-INTERNET-permission gate
and recorded two real OS DNS permission denials before mounting the scene.
The first unbridged probe terminated OkHttp's worker with SecurityException;
that failed APK and crash log were retained separately. The fixture-only DNS
exception bridge is described in `scripts/material-lab/README.md`.

The physical baseline video lasts 16.13 seconds, more than three default
4.5-second loader revolutions. Frames at 2 and 4 seconds show the segment moving
around the perimeter. Initial screenshots at an arbitrary phase cannot show
that a glow is permanently concentrated at the bottom. Native blur width,
clipping and tint still need a phase-aligned comparison with web. The user's
font scale remains unchanged; 390px/default-font web is not an exact geometric
match for this Pixel configuration. System bars/safe areas also differ.

Artifacts are written under `.local/material-comparison` (web) and
`.local/issue-663-material/baseline-offline-{x86_64,arm64}` (native): APK,
build/environment JSON, startup log, initial screenshot/UI XML, per-state
captures, and `composer-16s.mp4` on the Pixel. Large binaries/videos are not
committed. The web report records each role's bounds and external-request
checks. Native capture automation records bounds and scrolls to expose the
composer beyond the floating tab bar. Captures are diagnostic evidence;
contrast, parity and frame-budget acceptance require separate evaluation.

Validation: native fixture TypeScript check passes; isolated-device/APK guard
has 3 passing tests; source/icon references have 11 passing tests; web capture
has 34 passing states with no page errors or external HTTP requests. Android
release builds and guarded launches passed on the two recorded targets.
