# SettingsList — deprecated

Use [GroupedSection](./grouped-section.mdx) from `@oxy.so/bloom/grouped-section`.
The old names remain compatible aliases to the same implementation and retain
runtime identity; they are deprecated in TypeScript declarations.

| Deprecated | Canonical |
| --- | --- |
| SettingsListGroup | GroupedSection |
| SettingsListItem | GroupedSectionItem |
| SettingsListDivider | GroupedSectionDivider |
| SettingsListGroupProps | GroupedSectionProps |
| SettingsListItemProps | GroupedSectionItemProps |
| SettingsListDividerProps | GroupedSectionDividerProps |
| SettingsListGroupVariant | GroupedSectionVariant |

```tsx
import { GroupedSection, GroupedSectionItem } from '@oxy.so/bloom/grouped-section';

<GroupedSection title="General">
  <GroupedSectionItem title="Account" onPress={openAccount} />
</GroupedSection>
```

Legacy imports from `@oxy.so/bloom/settings-list` remain supported for migration; use the canonical subpath in new code.
