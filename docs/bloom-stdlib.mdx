# The Bloom standard library

The standard library is implicit in every package file: its names need no `import`, and a
file imports exactly what it uses. A name the package declares itself shadows it. It is
written in Bloom over a small set of JS primitives (`stdlib/Bloom/runtime.ts`) that only it
sees. Members marked `static` are called on the type (`Date.now`, `URL.parse(…)`); the others
on a value (`"a b".components(separatedBy: " ")`).

## Core

Bloom (core): String and Character, Array, Dictionary, Set, Optional, Result and Error.

Implicit in every package file: nothing is imported to use them. The built-in
members (`count`, `isEmpty`, `map`, `filter`, `contains`, `sorted`, `split`, …) are the
compiler's; these extend them, statically dispatched (`crate::extensions`).

### `struct UniqueID: Equatable, Hashable`

## Math

`abs`, `min`, `max`, `round`, `floor`, `ceil` and the `Int`/`Double` members
(`rounded()`, `clamped(…)`, …) are the compiler's; these complete them, with Foundation's

## Time

Bloom (time): `Date`, `Duration`, `Clock`, `Calendar` and formatting.

A `Date` is a value: an instant, as seconds since 1970-01-01T00:00:00Z (Swift's). At runtime and
in TS it is a JS `Date`, in both directions, as Swift's `Date` bridges to `NSDate`: a TS function
taking or returning a `Date` takes and gives this one. It is equal to another at the same
instant, encodes as an ISO 8601 string (`Codable`), compares with `<`, moves with `+`/`-` (in
seconds), and formats for a locale:

```swift
Text(post.createdAt.formatted(.relative))                       // "2 minutes ago"
Text(event.startsAt.formatted(date: .abbreviated, time: .shortened)) // "Nov 26, 2026, 6:30 PM"
Text(event.startsAt.formatted(.dateTime.month(.abbreviated).day()))   // "Nov 26"
```

### `struct HourStyle: Equatable`

## JSON

Bloom (I/O): `JSON` and `Codable`.

A struct or enum that conforms to `Codable` gets its decoder and encoder at compile
time (`crates/lang/src/codable.rs`), with no reflection: `T.decode`, `T.encode` and the
codec `T.self`, which the APIs here and `HTTPClient` take.

```swift
public struct Post: Codable, Equatable {
  public let id: String
  @CodingKey("created_at") public let createdAt: Date
  public var likes: Int = 0          // absent in the JSON: the default
  public let replyTo: String?        // absent or null: `none`
}

let post = try JSON.decode(Post.self, from: text)
let text = JSON.encode(Post.self, post)

```

Each field decodes by its type: `String`, `Int`, `Double`, `Bool`, `Date` (ISO 8601,
or milliseconds since 1970), `URL`, another `Codable` type, `[T]`, `T?` and
`[String: T]`. A case-only enum decodes from its case name. A value of the wrong type
throws a `DecodingError` naming the type and the field.

### `type JSONValue`

A JSON value as parsed: what the derived decoders read.

### `extension JSONValue`

Lenient reads of a JSON value, each `none` when the value is not of that type, so a chain of them never throws: `body?["error"]?["message"]?.string`. `value["key"]` is the member of an object (`none` when it is not an object, or has no such key, or it is `null`), `value[i]` the element of an array.

- `var string: String?`: The value as a string.
- `var number: Double?`: The value as a number (finite).
- `var int: Int?`: The value as an integer (a number with no fraction, within `Int`'s exact range).
- `var bool: Bool?`: The value as a Boolean.
- `var array: [JSONValue]?`: The value as an array's elements.
- `var object: [String: JSONValue]?`: The value as an object's members.

### `extension Error`

- `var jsValue: JSONValue?`: The thrown value itself, to read leniently where no type fits it (a TS library's error object): `error.jsValue?["response"]?["data"]?["error"]?.string`. `none` when the thrown value was `null` or `undefined`.

### `struct DecodingError: Equatable`

- `let at: String`

### `func jsonObject(_ entries: [String: JSONValue]) -> JSONValue`

## Concurrency

Bloom (concurrency): `Task`, `TaskGroup`, `sleep(for:)` and `AsyncStream`.

A view's work runs in `.task { }` (cancelled when the view leaves; `Task.signal` is its
cancellation, which `HTTPClient` and `sleep(for:)` take, and take by themselves in a `.task`
when given none). `await Task.cancellation` returns once the task is cancelled, so a setup's
teardown is a `defer` before it:

```swift
.task(id: room) { let s = socket.join(room); defer { socket.leave(s) }; await Task.cancellation }

```

and a debounce is `.task(id: query) { try? await sleep(for: .milliseconds(300)); search(query) }`.
Work that outlives a view starts with `Task.run`:

```swift
let upload = Task.run { signal in try await api.perform(.post, "media", json: body, cancellation: signal) }
upload.cancel()
```

### `type TaskSignal`

A cancellation signal: `Task.signal` in `.task { }`, or a `Task`'s own.

### `type TaskHandle<T>`

The runtime's handle of a started task.

### `type Pending<T>`

A value not yet there.

### `type Channel<T>`

The runtime's broadcast channel.

### `func sleep(for duration: Duration, cancellation: TaskSignal? = none) async throws`

Waits `duration`; throws a cancellation when `cancellation` fires first.

### `func isCancelled(_ error: Error) -> Bool`

Whether `error` is a task's cancellation (not a failure to report).

### `struct Task<Success>`

Work started now, which runs on until it ends or is cancelled.

- `let handle: TaskHandle<Success>`

### `extension Task`

- `static func run(_ work: (TaskSignal) async throws -> Success) -> Task<Success>`: Starts `work`, which receives the task's cancellation signal.
- `func cancel()`: Asks the task to stop: its signal fires.
- `func value() async throws -> Success`: The task's result, or what it threw.
- `var isCancelled: Bool`: Whether `cancel()` was called.

### `struct TaskGroup<Element>`

Runs work concurrently and gathers the results, in order.

- `let tasks: [Task<Element>]`

### `extension TaskGroup`

- `static func start(_ works: [(TaskSignal) async throws -> Element]) -> TaskGroup<Element>`: Starts every one of `works` now.
- `static func map<T>(_ items: [T], _ transform: (T) async throws -> Element) -> TaskGroup<Element>`: `transform` of each of `items`, run concurrently; the results in `items`' order.
- `func values() async throws -> [Element]`: Every result, in order; the first failure cancels the others and is thrown.
- `func cancelAll()`: Cancels every task.

### `struct AsyncStream<Element>`

Values over time, to every subscriber: what a socket or a sensor sends.

- `let channel: Channel<Element>`

### `extension AsyncStream`

- `static func make() -> AsyncStream<Element>`: A stream nothing has been sent on yet.
- `func yield(_ value: Element)`: Sends `value` to every subscriber.
- `func finish()`: Ends the stream: subscribers get `onFinish`, and later ones get it at once.
- `func subscribe(_ each: (Element) -> Void, onFinish: () -> Void = {}) -> () -> Void`: Calls `each` with every value sent from now on; returns the unsubscribe.

### `func actorIsolated<A, T>(_ actor: A, _ work: () -> T) async -> T`

What an `actor`'s method lowers onto: `work` runs once the actor's earlier calls have ended, one at a time (a per-instance queue).  actor Counter { var count = 0 func increment() -> Int { count += 1; return count } } let n = await counter.increment()

### `func actorIsolatedThrowing<A, T>(_ actor: A, _ work: () throws -> T) async throws -> T`

`actorIsolated` for a method that throws: its error reaches the caller.

### `func actorIsolatedAsync<A, T>(_ actor: A, _ work: () async -> T) async -> T`

`actorIsolated` for an `async` method: the next call waits for its end, awaits included.

### `func actorIsolatedAsyncThrowing<A, T>(_ actor: A, _ work: () async throws -> T) async throws -> T`

`actorIsolatedAsync` for a method that throws.

### `func refreshAction(_ state: Binding<Bool>, _ action: () async -> Unit) -> Binding<Bool>`

What `.refreshable { await model.refresh() }` lowers onto: the pull sets `state`, which runs `action` and clears it when the action ends (the spinner shows until then).

- `var flags: String`

### `struct RegexMatch: Equatable`

One match: its text, where it starts (a character offset, as `String.count` counts; Swift's model on every backend) and its groups.

- `let text: String`
- `let start: Int`
- `let groups: [String?]`: The numbered groups, from group 1 (`none` where a group did not take part).
- `let named: [String: String]`: The named groups that took part (`(?<handle>\\w+)`).

### `struct RegexError: Equatable`

A pattern that is not a valid expression.

- `let pattern: String`
- `let message: String`

### `extension Regex`

- `init(_ pattern: String) throws`: The expression `pattern`, checked (Swift's `try Regex("…")`): throws a `RegexError` when it is invalid.
- `static func compile(_ pattern: String, flags: String = "") throws -> Regex`: The expression, checked: throws a `RegexError` when `pattern` is invalid.
- `func matches(in text: String) -> [RegexMatch]`: Every match in `text`, in order.
- `func firstMatch(in text: String) -> RegexMatch?`: The first match in `text`, or `none`.
- `func isMatch(_ text: String) -> Bool`: Whether the expression matches somewhere in `text`.
- `func replacing(in text: String, with replacement: String) -> String`: `text` with every match replaced (`$1`, `$<name>` insert groups).
- `func split(_ text: String) -> [String]`: The parts of `text` between matches.

### `extension String`

- `func wholeMatch(of regex: Regex) -> RegexMatch?`: The match of `regex` spanning the whole string, or `none`.
- `func firstMatch(of regex: Regex) -> RegexMatch?`: The first match of `regex`, or `none`.
- `func matches(of regex: Regex) -> [RegexMatch]`: Every match of `regex`, in order.
- `func contains(_ regex: Regex) -> Bool`: Whether `regex` matches somewhere in the string.
- `func replacing(_ regex: Regex, with replacement: String) -> String`: The string with every match of `regex` replaced (`$1`, `$<name>` insert groups).
- `func split(separator: Regex) -> [String]`: The parts of the string between the matches of `separator`.

### `extension RegexMatch`

- `func group(_ n: Int) -> String?`: Group `n` (1 is the first, 0 the whole match), or `none`: past the last group, or where the group did not take part in the match.
- `var end: Int`: Where the match ends (a character offset, exclusive).

## Logger

Bloom: `Logger`, levelled logs for a subsystem and category.

```swift
let log = Logger(subsystem: "mention", category: "feed")
log.info("loaded \(page.items.count) posts")
log.error("like failed: \(error.localizedDescription)")

```

Lines go to the console (`debug` only in development builds) unless a sink is
installed (a crash reporter's binding, a test).

### `enum LogLevel`

How severe a log line is.

- `case debug`
- `case info`
- `case notice`
- `case warning`
- `case error`
- `case fault`

### `struct Logger: Equatable`

Logs for one part of an app.

- `let subsystem: String`: The app or library (`mention`).
- `var category: String`: The part of it (`feed`, `auth`).

### `extension Logger`

- `func log(_ level: LogLevel, _ message: String)`: A line at `level`.
- `func debug(_ message: String)`: Detail for development: dropped from release builds.
- `func info(_ message: String)`: What happened, for following along.
- `func notice(_ message: String)`: Worth noticing, not wrong.
- `func warning(_ message: String)`: Something went wrong and was recovered from.
- `func error(_ message: String)`: Something failed.
- `func fault(_ message: String)`: A bug: a state the code holds impossible.

### `func print(_ message: String)`

Writes `items` to the console, separated by spaces (Swift's `print`).

## Localization

Bloom (i18n): `String(localized:)`, `Text("key")` checked against the package's
catalogs at compile time (`Resources/Localizable/<locale>.json`), plural rules and `Locale`.

```swift
Text("feed.title")                                   // a key of en.json: localized
Text(String(localized: "feed.count", count: posts.count))
Text(String(localized: "greeting", args: ["name": user.name]))

```

A catalog maps keys to strings, or to plural forms by CLDR category:

```swift
{ "feed.title": "Home",
  "feed.count": { "one": "{count} post", "other": "{count} posts" },
  "greeting": "Hello, {name}" }
```

### `struct Locale: Equatable`

A language and region (`en`, `es-ES`, `pt-BR`), as BCP 47 writes it, and the clock its times are written in: the language's own (`none`), or an `HourCycle`.

- `let identifier: String`
- `let hourCycle: HourCycle?`

### `enum HourCycle`

The hours of a clock (Swift's `Locale.HourCycle`; Intl's `hourCycle`): `.oneToTwelve` is "6:30 PM" in every language, `.zeroToTwentyThree` "18:30".

- `case zeroToEleven`: 0 to 11, with the AM/PM (Intl's `h11`).
- `case oneToTwelve`: 1 to 12, with the AM/PM (Intl's `h12`).
- `case zeroToTwentyThree`: 0 to 23 (Intl's `h23`).
- `case oneToTwentyFour`: 1 to 24 (Intl's `h24`).

### `extension Locale`

- `static var current: Locale`: The locale strings are shown in: the one set with `Locale.prefer`, else the device's.
- `static func prefer(_ locale: Locale)`: Shows strings in `locale` from now on (a language setting in the app).
- `var languageCode: String`: The language part (`es` of `es-ES`).
- `var regionCode: String?`: The region part (`ES` of `es-ES`), or `none`.
- `func pluralCategory(_ n: Double) -> String`: The CLDR plural category of `n` here: `zero`, `one`, `two`, `few`, `many` or `other`.

### `extension String`

- `static func localized(_ key: String, args: [String: String] = [:], count: Double? = none, locale: String? = none) -> String`: The string for `key` in the current locale, `{name}`s replaced from `args` and the plural form chosen by `count` (`{count}` replaced too); `key` itself when missing. `count` is a `Double` (an `Int` widens to it): CLDR plural rules take decimals too (`1.5` is `other` in English). `String(localized: "…")` is this, checked against the catalogs. In a view, it is looked up in the `locale` the view read with `useLocalization()` (the compiler passes it), so `Locale.prefer` re-draws the view.

### `func useLocalization() -> String`

The preferred locale's identifier, read so the view re-draws when `Locale.prefer` changes it. A view that shows localized strings reads it once; the compiler writes the read.

### `func registerLocalizations(_ locale: String, _ catalog: JSONValue)`

Registers a catalog (`bloom build` registers the package's own at startup).

## Navigation

BloomUI (navigation): `NavigationStack` with typed routes, tabs, sheets and deep links.

```swift
public enum Route: Routable {
  case feed                 // the first case is the root: "/"
  case post(id: String)     // "/post/[id]"; demo://post/42 opens it
  case settings
}

NavigationStack(root: Route.feed, sheets: [Route.settings]) { route in
  switch route {
  case .feed: FeedScreen()
  case .post(let id): PostScreen(id: id)
  case .settings: SettingsScreen()
  }
}

NavigationLink(Route.post(id: post.id)) { PostRow(post: post) }
Button("Settings") { push(Route.settings) }

```

The routes are the enum's cases: `bloom build` reads the enum from the module graph and
writes the router's route table from it (each case a route, its associated values the
route's typed parameters, `sheets:` presented over the stack, `tabs:` the tab bar's
pages), so a deep link (`<app>://post/42`, a web URL) opens the screen the
`destination` draws for `Route.post(id: "42")`.

### `protocol Routable`

An enum whose cases are the app's screens: `NavigationStack`'s routes.

### `struct Tab<R>`

A page of the tab bar: its route (a case without associated values), its title and its icon (a Bloom icon name, `"home"`, `"settings"`).

- `let route: R`
- `let title: String`
- `let icon: String`

### `func NavigationStack<R>(root: R, tabs: [Tab<R>] = [], sheets: [R] = [], destination: (R) -> View) -> View`

The app's navigation: `root` first, every other route pushed over it (`sheets:` presented as sheets), each drawn by `destination`. With `tabs:`, the root is the tab bar's pages.

### `func push<R>(_ route: R)`

Goes to `route`: pushed, or presented when it is one of the stack's `sheets:`.

### `func replace<R>(_ route: R)`

Goes to `route` in place of the screen in front.

### `func dismiss()`

Back to the screen under this one (or closes the sheet in front).

### `func href<R>(_ route: R) -> String`

The address of `route` (`"/post/42"`): what a deep link or a web URL to it reads.

## Data

Bloom (data): `@Model` types held by key, read by `@Query`, filled by a `Source`,
changed optimistically by a `Mutation`, and fed by `Realtime` events.

```swift
@Model public struct Post: Codable {
  @Attribute(.unique) public let id: String
  public var likes: Int
  public let createdAt: Date
}

Post.store.insert(post)
Post.store.update(post.id) { $0.liked(true) }

struct Feed: View {
  @Query(Post.self, sort: \.createdAt, order: .reverse) var posts: [Post]
  var body: some View { List(posts) { post in PostRow(post: post) } }
}

```

`@Model` derives `Post.store` at compile time, beside `Codable`'s `Post.self`, keyed by
the `@Attribute(.unique)` field (else `id`). A view's `@Query` re-renders when one of
its records changes, and only then. Records persist across launches: Android and iOS
copy them to SQLite in the background (`@oxy.so/bloom-data/sqlite` on `expo-sqlite`);
the web and tests keep them in memory.

### `type ModelHandle<T>`

The data layer's records of one `@Model` type.

### `type SourceHandle<T>`

The data layer's server list.

### `type MutationHandle<A, R>`

The data layer's mutation (its `action`).

### `type EventSocket`

What `Realtime` listens on: a socket with `on(event, listener)` and `off` (socket.io's).

### `enum SortOrder`

A `@Query`'s order.

- `case forward`
- `case reverse`

### `struct ModelStore<T>`

The records of one `@Model` type, by key: what `@Model` derives as `T.store`.

- `let name: String`: The type's name: its records' namespace on disk.

### `func modelStore<T>(_ name: String, key: KeyPath<T, String>, persist: Bool = true) -> ModelStore<T>`

What `@Model` writes for `T.store`: the records of `name`, keyed by `key`.

### `extension ModelStore`

- `func get(_ id: String) -> T?`: The record with key `id`, or `none`.
- `func insert(_ record: T)`: Stores `record`, replacing the one with its key.
- `func insertAll(_ records: [T])`: Stores every one of `records`.
- `func update(_ id: String, _ change: (T) -> T) -> Bool`: Replaces the record `id` by `change` of it. Inside a `Mutation`'s `optimistic`, the change is the action's, rolled back when it fails. Whether `id` was held.
- `func delete(_ id: String) -> Bool`: Removes the record `id`, in memory and on disk. Whether it was held.
- `var all: [T]`: Every record held, in the order they were first inserted.
- `func load() async throws`: Reads the records from the device's copy (a `@Query` does this on its first read).

### `func useQuery<T, V>(_ store: ModelStore<T>, sort: KeyPath<T, V>? = none, order: SortOrder = .forward, filter: ((T) -> Bool)? = none) -> [T]`

What `@Query(T.self, sort:order:filter:)` lowers onto: `store`'s records, filtered and sorted (by a number, string, `Bool` or `Date` field), re-read when one of them changes.

### `func useRecordQuery<T>(_ store: ModelStore<T>, id: String?) -> T?`

What `@Query(T.store, id: x)` lowers onto: one record, re-read when it changes.

### `struct SourcePage<T>`

One page of a `Source`: its records and the next page's cursor (`none`: the last).

- `let items: [T]`
- `let next: String?`

### `struct Source<T>`

A server list of a `@Model` type's records, read a page at a time and kept on the device. `@Query(source)` in a view reads it when it is due.  let home = Source(Post.store, name: "home") { cursor, signal in let page = try await api.get("feeds/home", as: FeedPage.self, query: ["cursor": cursor ?? ""], cancellation: signal) return SourcePage(items: page.items, next: page.nextCursor) }

- `let name: String`

### `extension Source`

- `static func make(_ store: ModelStore<T>, name: String, _ load: (String?, TaskSignal) async throws -> SourcePage<T>) -> Source<T>`: The list `name` of `store`'s records, whose pages `load(cursor, cancellation)` reads.
- `func refresh() async`: Reads the first page again (a failure keeps the list as it was).
- `func loadMore() async`: Reads the next page, if there is one.

### `func useSource<T>(_ source: Source<T>) -> [T]`

What `@Query(source)` lowers onto: the source's records, in its order.

### `struct Mutation<Input, Output>`

A change shown at once (`optimistic`, on `@Model` stores) and settled by `perform`: when it throws, the optimistic change is rolled back. (Named as Services' `run`; BloomUI's `Action` is the action bar's node.)  let like = Mutation.make("like", optimistic: { (post: Post) in _ = Post.store.update(post.id) { $0.liked(!post.isLiked) } }) { post in try await api.post("posts/\(post.id)/like") } await like.run(post)

- `let name: String`

### `extension Mutation`

- `static func make(_ name: String, optimistic: ((Input) -> Unit)? = none, _ perform: (Input) async throws -> Output) -> Mutation<Input, Output>`
- `func run(_ input: Input) async -> Output?`: Runs the mutation: its result, or `none` when it failed (and was rolled back).

### `struct Realtime`

A socket's events written into `@Model` stores, applied together once per frame.


### `extension Realtime`

- `static func listen(_ socket: EventSocket, _ handlers: [String: (JSONValue) -> Unit]) -> Realtime`: Calls each handler with its event's payload; `cancel()` stops listening.
- `func cancel()`: Stops listening.
