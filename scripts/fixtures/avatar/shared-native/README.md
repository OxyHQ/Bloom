# Physical shared-context audit fixture

Copy this directory to an isolated local app, install its pinned dependencies, then install the real `@oxy.so/bloom-avatar-native` tarball using a unique filename. Do not copy its source into the app or leave a duplicate local Expo module. Run `bunx expo prebuild --platform android`, start Metro on port 8098, and build with `./gradlew assembleDebug -PreactNativeDevServerPort=8098` in `android/`. Install only this dedicated `so.oxy.bloom.avatar.gpulab` APK on an authorized unlocked test device.

Serve the matching built Bloom runtime at port 6007. Reverse ports 6007, 8098 and 8099 for that device. Start `python3 control.py <output-directory>`. Write JSON commands to that directory's `command.json`; each distinct `id` produces `<id>-native.json`. Example: `{"id":"eight-idle","count":8,"paused":false,"warmup":15000,"duration":10000}`. Use `characters` from `mixed-characters.json` for the appearance check. Commands also support `work`, `reaction`, `scroll:"end"|"top"`, `snapshot:true`, and `coldFrame:true`.

`before`/`after` count actual Android SurfaceTexture updates, not engine ticks. Initial work/reaction keys remain undefined. The long workingCycles value keeps the work pose observable and is test-only. `NativeAudit.js` performs explicit first-frame readback only when requested; production animation performs no such readback. Cold first delivered held idle is compared against the identical repeated pose on the same GPU. Snapshots include an image data URI and should be stripped from curated reports after checking alpha.

Verify `compatible:true`, actual installed APK hash, package runtime/manifest hashes, ready view count, all visibility flags and nonzero size. Cold loading can exceed the command warmup, particularly for mixed work; wait for all twelve ready before interpreting that check. For lifecycle checks, pause, scroll all cells away, return them, and finally set count 0; inspect actual update deltas and remaining contexts. Match pixel backing and quality rather than only nominal view size when comparing WebView.

Keep device serials, process IDs and unrelated app information out of published evidence. Preserve the app and tarball locally for reproduction; remove only test APKs/forwards when all device work finishes. This is an isolated React Native debug/Hermes app, not a production app release benchmark.
